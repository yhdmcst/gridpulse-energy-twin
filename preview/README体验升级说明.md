## 已包含的升级

- 结构一致的中英文 README、折叠详情与文档导航。
- 自动适配深浅色的品牌横幅与 SVG 技术路线图。
- 28 秒数据驱动动画：播放、暂停、重播、进度拖动、章节、倍速、中英文与主题切换。
- README 内的 GIF 预览，以及减少动态效果时的静态回退。
- 实际 Streamlit 应用截图、源数据哈希与第三方图标完整许可。
- 仓库内的单文件动画、双语 HTML 预览和四张预览截图。
