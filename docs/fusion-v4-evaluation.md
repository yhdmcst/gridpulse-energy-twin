# 第四轮结果再评估

评估日期：2026-10-26。先完成本评估，再执行第五轮。

## 总体判断

第四轮是可复核的负结果：物理实现通过，但没有新策略通过多指标准入。
可以据此设计下一轮探索，不能据此替换正式默认方案或宣称 P95 已解决。

| 维度 | 评价 | 依据 |
|---|---|---|
| 可复现性 | 通过 | 再次独立核对 234 个哈希、120 条轨迹、150 组区间与选择规则 |
| 物理一致性 | 通过 | 名义与重规划守恒、硬边界、连续性、日末恢复通过；重放缺口保留 |
| 实用性能 | 未准入 | 所有新配置违反至少一项预先规定门槛 |
| 因果解释 | 有限 | 局部峰值限制、SOC 路径和目标函数一起改变，不能只归因于 SOC |
| 外推能力 | 不足 | 所有年份此前看过，三个种子不等于三个独立电网 |
| 创新证据 | 工程层面 | 支持审计与参考约束研究，不支持“新的物理定律”或精度全面提升 |
| 资源可行性 | 可继续 | 固定预测器，只需小规模 CPU 优化，不必等待 A100 |

## 主要问题及证据边界

1. **高优先级：P95 收益伴随最高点回升。** tail_dynamic_0 验证期平均
   P95 下降 160.28 MW，但各种子最高点上升 338.89–510.51 MW，
   不满足允许上升 25 MW 的门槛。不得只展示较好的年份或平均指标。
2. **重要：局部最优峰值不是跨策略的同一约束。** 不同策略的 SOC 和
   窗口最优值不同，所以每个窗口都“最优”仍可能改变全期实测极值。
3. **重要：能量债务解释需要真正消融。** 重新计算验证期轨迹，
   tail_dynamic_0 在约 3.21%–3.87% 小时的 SOC 低于参考策略，
   最大差额约 4076.09 MWh。三个候选最高点所在小时的 SOC 也低于参考。
   这与债务假设一致，但不是其为唯一原因的证明。
4. **重要：零对比不是等效性证据。** 最终选择回退 legacy，
   所以选择策略减 legacy 的零差值和零区间是相同轨迹的恒等结果。
5. **限制：验证期复用与已知评价年份。** 校准、checkpoint 和策略筛选
   多次使用相同验证期，存在适配与样本内乐观风险。区块区间也只对固定
   模型和观测日有条件，不能作为实网可靠性或新电网有效性的保证。

## 下一轮为什么值得做

验证期实际负荷最高 1% 的 50 个小时，在三个固定模型下，
参考策略的 h1 上界受控负荷均超过固定尾部门限。
这支持尝试在“上界已高”的小时限制新策略不能增加净储能负荷，
并约束实际下一步 SOC 不低于参考策略，避免提前透支参考电量。
这仍是条件性设计依据，不是上界在未来必然覆盖实际值的证明。

第五轮只测试五个预先声明的配置：单独尾部目标、加 SOC 债务约束、
再加充放电净负荷保护，以及两种压峰目标消融。
参考状态只读取当前和过去，绝不使用未来参考轨迹作为控制信息。
原有逐种子峰值、P95、吞吐和损耗门槛全部保留。

## 决策

允许隔离执行第五轮探索，禁止放宽第四轮门槛或修改历史结果。
无合格候选时仍回退 legacy。详细量化诊断保存在
`outputs/fusion_v4_recovery_review.json`，不覆盖第四轮工件。
