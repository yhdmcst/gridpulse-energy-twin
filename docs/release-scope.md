# 发布内容与原项目对应

## 版本依据

本仓库提取自原完整项目中的唯一主版本 `gridpulse-energy-twin/03_源代码`，
以 `fusion_v8` 与 `envelope_tail` 为应用及证据基准。
发布整理未改变原始研究算法、冻结结果、评价数据或候选选择。

## 公开内容

| 公开位置 | 原项目来源与处理 |
| --- | --- |
| `src/`、`tests/`、`scripts/` | 原主版本源码；增加发布准备入口和对应测试 |
| `experiments/` | 原 V1–V8 协议与 V8 冻结源码 |
| `artifacts/evidence-*.zip` | V8 全部结果、独立复算所需的 V3/V6/V7 最小依赖，以及三份标准化数据快照 |
| `evidence/v8/` | 冻结指标、选择、状态、manifest 与工件哈希，便于 GitHub 在线阅读 |
| `evidence/data/` | Energy-Charts 2021/2022 来源、转换与校验记录 |
| `evidence/analysis/` | 原 V8 分析摘要与溯源 |
| `docs/reports/` | 主版本唯一技术报告 PDF，改用便于公开引用的英文文件名 |
| `report_assets/` | 报告 Markdown 源稿、图表及其数据，移除本地排版调试副本 |
| `assets/readme/` | 原路演概念图、研究图表，以及本次从实际应用采集的截图 |
| `.github/` | 新增自动检查与协作模板 |
| `docs/showcase/` | 数据驱动的双语 HTML/SVG 动画，附来源哈希与第三方图标许可 |
| `preview/` | 单文件动画、双语 README 浏览器预览、四张截图与统一入口；全部属于仓库交付 |

ZIP 中保留原始文件字节和路径，不重采样、不转换 CSV、不修改原冻结哈希。
恢复后的证据路径仍为 `outputs/...` 和 `data/processed/...`。
发布清单的 250 个文件与 V8 原清单的 204 个工件是不同统计范围。

## 保留在本地的内容

历史原始提交包、重复交付包、完整 PPT 制作工程、全部旧轮次实验输出、
本地 Python 运行环境、依赖缓存、工作记录、私人配图和个人工具设置不进入公开仓库。
用户原有文件不因本次发布整理而被删除。

原有文档中的历史工件引用用于研究溯源，不代表这些前序工件都存在于本发布包。
`scripts/reporting/`、`scripts/ppt/`、部分提交打包脚本与远程执行脚本是历史工具，
可能依赖原项目层级、平台字体或单独安装的审校工具；它们不属于本仓库承诺的便携启动流程。
V8 界面、发布准备、当前回归测试与独立 V8 核算则构成本次整理的验证范围。

## 许可边界

代码 MIT 许可不替代数据许可。OPSD 数据涉及其发布包及上游来源条款；
Energy-Charts 的归属和记录单独保留。发布者仍需根据原始条款判断进一步再分发和具体用途。
竞赛官方通知、规则和模板 PDF 未复制到公开仓库；第三方参考链接保留，不附带参考仓库副本。

本项目不包含新增作者身份、机构署名、虚构的 DOI、获奖信息或未运行的 CI 成功标记。

README 体验升级增加主题感知横幅、SVG 路线图、GIF 预览和可选手动 Pages 工作流。
动画不是应用录屏或实机视频；它选取冻结证据的一个说明日，不能替代完整评价。
