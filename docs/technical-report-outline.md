# V8技术报告结构

报告采用赛事附件2的章节顺序：

1. 摘要：问题、方法、主要结果与研究条件。
2. 项目背景与意义：风光波动、预测到执行的失配及项目目标。
3. 技术方案与实现：架构、因果预测、物理状态、恢复约束、保守规划和故障门控。
4. 实验结果与分析：预测消融、窗口与目标取舍、参数误差、SOC反馈、V8全条件和故障回放。
5. 创新点与应用前景：状态级孪生、恢复知识进入规划、可复核实验设计及设备接入路径。
6. 结论：30/30恢复、11/30性能预算、范围外失败及后续研究。
7. 参考文献与附录：数据、框架、算法及原始工件位置。

编辑入口为 `scripts/reporting/competition_template.md`，生成文件位于
`report_assets`，发布后参赛目录只保留 `GridPulse-技术报告.pdf`。
