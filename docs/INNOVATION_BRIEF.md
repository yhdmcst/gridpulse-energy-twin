# V8方法贡献

## 状态级能源孪生

用一条逐小时轨迹连接预测、请求、实际动作、参考电量和SOC反馈。
控制器与执行仿真器分别使用声明模型和场景实际参数，使模型失配的影响可以定位。

## 恢复知识进入规划

V8将875 MW、效率0.85的下界同时用于主规划和虚拟参考，配合因果参考电量、
尾部目标和恢复监督。范围内候选30/30条轨迹恢复电量，自然主优化失败和监督干预均为0。
相对V7的峰值、P95和损耗变化按全部条件报告。

## 可复核评价

数据模型采用同输入对照与配对种子；旧预测包按原始lead对齐区间。
V8固定seed42，保留验证期选择、全部评价、范围外失败及故障原因。
结果回放直接读取冻结CSV，并核对文件哈希、时间连续性和能量平衡。

研究范围是公开德国数据的聚合储能仿真。后续结合SOC误差界、独立地区数据、
设备与网络模型检验应用条件。
