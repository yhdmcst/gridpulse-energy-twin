# 第四轮：尾部目标与储备规则消融

执行日期：2026-10-26。状态：计算、回传、独立复算完成。

## 结论

**本轮没有找到同时通过预先规定保护门槛的改进配置，第三轮六小时配置继续作为实验基线，正式默认方案不变。**

这不是程序失败或物理核算失败，而是性能准入失败：

- 尾部目标确实可以降低部分 P95，但验证期最高点回升约 339–638 MW，
  超过预先允许的 25 MW。
- 精确两阶段压峰在三个种子平均上有小幅验证期收益，
  但 seed43 的 P95 变差 27.18 MW，不满足逐种子限制。
- 去掉建议储备、只保留硬 SOC 下限，会在某些年份改善 P95，
  但验证期的吞吐、损耗或 P95 不合格，不能根据后续年份重新挑选。
- 因此未替换默认应用、正式控制器或前三轮证据。
  第三轮相对一小时规划的 P95 回退仍未解决，不能包装成本轮已经全面改进。

## 本轮做了什么

不重训模型、不使用 GPU。复用第三轮六时距 HGB 和 data MLP
三个固定种子 42/43/44，保持预测、区间、控制门限与完整 UTC 日完全一致。
物理模型仍为容量 30000 MWh，初始/运行上限/日末 15000 MWh，
硬下限 4500 MWh，双向功率 1250 MW，各方向效率 0.92。

共七个控制器：

| 配置 | 优化目标 | 建议储备 | 局部预测峰值放宽 |
|---|---|---|---:|
| legacy | 第三轮原控制器 | 原动态规则 | 原算法 |
| peak_dynamic | 先最小峰值，再最小吞吐 | 动态 | 0 MW |
| peak_physical | 先最小峰值，再最小吞吐 | 仅硬下限 | 0 MW |
| tail_dynamic_0 | 先最小峰值，再减少尾部超门限负荷 | 动态 | 0 MW |
| tail_dynamic_250 | 同上 | 动态 | 250 MW |
| tail_physical_0 | 同上 | 仅硬下限 | 0 MW |
| tail_physical_250 | 同上 | 仅硬下限 | 250 MW |

尾部门限固定为共同验证期实际净负荷 q90，即 **51981.30 MW**。
第二阶段尾部代价为预测超门限正部的均值，加 0.001 倍吞吐。
它是便于线性优化的代理，不是直接优化全期经验 P95，也不是 CVaR 保证。

`physical` 只表示取消建议储备、仍保留硬物理下限，不是新增物理 AI 模型。
两阶段都使用点预测；区间上界仍决定放电门限和动态储备。
终端可达性、补电负荷和损耗全部保留，未注入免费电量。

同样本规模：

|---|---:|---:|
| 验证 | 208 | 4992 |
| 原测试 | 417 | 10008 |
| 2021 | 364 | 8736 |

共 28 条验证轨迹、84 条评价轨迹、8 条压力轨迹。
84 条中 12 条 legacy 逐字节复用第三轮，另外 72 条为新计算。
全部评价年份此前已被检查，依然属于探索性研究，不是新的独立留出。

主流程约 **516.14 秒，即 8.60 分钟**，不含传输、预检与本地复算。
最多三个 CPU 工作进程，OMP/MKL/OpenBLAS 线程设置为 1。
沿用原远程环境，没有安装依赖或干预其他 GPU 任务。

## 先验证选择，后评价

方案在执行前冻结于 `experiments/fusion_v4/protocol.md`。
仅用三个 data 种子的验证期决定一个全局配置；HGB 不参与选择。

每个种子必须同时满足：

- 物理与终端审计通过；
- 最高受控净负荷不超过其 legacy 最高点加 25 MW；
- 吞吐和转换损耗分别不超过其 legacy 的 110%；
- P95 不超过其 legacy 加 1 MW。

还要求三个种子平均 P95 至少下降 1 MW。合格配置按平均 P95、
平均损耗、名称依次选择；没有合格配置则保留 legacy。
没有因结果不理想而扩大网格、放宽门槛或更换种子。

选择在北京时间 **2026-10-26 15:57:21** 冻结，随后才解析评价期输入。
回执包括验证结果、输入和方案哈希。校准与选择复用验证期，
仍可能有样本内乐观偏差，不构成确认性统计检验。

### 一个明确的峰值失败案例

验证期 2019-01-24 17:00 UTC，固定 data_seed42：

- 两配置 h1 预测相同，约 73514.62 MW；实际负荷 72635 MW。
- legacy：动作前 SOC 10362.28 MWh，放电 1053.68 MW，
  受控负荷 71581.32 MW。
- tail_dynamic_0：动作前 SOC 9285.81 MWh，放电 517.30 MW，
  受控负荷 72117.70 MW。
- 该小时两者下一步最低可达 SOC 都是 8100 MWh。

局部窗口里的目标、此前电量轨迹和当下动作分配已经改变。
“每个窗口都限制在它自己的最优预测峰值”不等于控制器之间拥有相同的
SOC 状态，也不保证整段真实最高点不变。不能把局部约束当成全局实测保证。
此案例用于诊断，不单独证明 SOC 差异是全部差异的唯一原因。
