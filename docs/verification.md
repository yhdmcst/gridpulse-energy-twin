## 发布适配

除仓库结构、文档和展示素材外，新增内容为标准库证据准备脚本、启动包装入口、
安全恢复测试、媒体响应回归测试与 GitHub 协作配置。
原算法、冻结 CSV、原候选选择及其失败结果未因展示目的改变。

真实浏览器测试发现 Streamlit 1.58.0 搭配 Starlette 1.10.0 时，媒体压缩接口不兼容，
图片会返回 HTTP 500。发布版固定 Starlette 0.49.3，并对有/无 GZip 的 PNG 响应增加测试。
该约束是本次验证的兼容组合，不构成对任何依赖版本的长期安全认证。
