# GridPulse V8 结果导读

## 项目问题

净负荷预测进入储能规划后，模型误差、功率限幅和转换损耗可能造成日末电量欠账。
V8把可恢复资源的下界放入规划模型，再通过逐小时SOC反馈检验实际执行。

## 当前界面

| 页面 | 主要内容 |
|---|---|
| 闭环回放 | V8净负荷、电量、恢复下界、请求与实际功率、逐小时故障日志 |
| 实验对照 | 全条件指标；V8候选、V8参考消融及V7监督基线 |
| 技术路线 | 因果预测、保守规划、物理执行、SOC回传的模块对应和状态方程 |
| 工件核对 | 实验版本、锁定候选、所选轨迹和SHA-256 |

默认打开2022年 `envelope_tail`。年份、预测延迟、设备条件和故障条件对应原实验中的有效组合。
2021/2022均为1月2日至12月30日，每年363个完整UTC日。

## 结果

候选30条范围内轨迹恢复日末电量，11条同时通过全部性能预算。
其中范围内包括两年、两种预测条件、六类设备参数形成的24条健康轨迹，以及6条计划故障轨迹。
750 MW/0.80范围外试验的最大日末欠账为642.96/589.59 MWh。

恢复成功和峰值改善需分别读数。名义fresh6条件下，V8相对V7的最高点差为
+28.57/+48.16 MW；2022年的P95差为+49.40 MW。
组合误差fresh6条件下最高点差为+54.88/+271.48 MW，P95差为-89.77/+24.10 MW。

## 方法假设

固定data_seed42及已校准区间；SOC准确即时回传；功率875 MW、效率0.85下界预先给定。
故障注入覆盖过期预测和求解服务中断。设备与电网接入研究另需遥测误差、网络和成本模型。

V1-V7记录用于说明方法演进和构造匹配对照。当前主结果、界面和技术报告统一使用V8。
