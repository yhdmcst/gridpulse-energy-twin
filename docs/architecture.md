# V8 技术路线

## 数据与信息流

```text
德国小时负荷 / 风电 / 光伏
          |
UTC 对齐、质量检查、滞后与移位滚动特征
          |
固定 data_seed42 -> 六时距预测 -> 原始 lead 对齐的误差区间
          |
预测时钟与服务门控
          |
875 MW / 0.85 保守模型 -> 尾部目标 + 因果参考电量
          |
恢复监督 -> 请求功率
          |
场景实际功率 / 效率 / SOC 限幅 -> 实际动作
          |
电量更新 -> 下一小时 SOC 反馈
          |
逐小时轨迹 -> 物理审计 -> 同条件结果对照 -> V8 界面回放
```

## 模块对应

| 阶段 | 代码 | 关键输入与输出 |
|---|---|---|
| 特征与训练 | `src/physics_forecast.py`、`src/multihorizon_fusion.py` | 截至上一小时的观测，直接预测六个时距 |
| 旧包适配 | `src/delayed_forecasts.py` | 延迟后保留原 h2-h6 或 h4-h6 及对应区间 |
| 保守规划 | `src/envelope_planning.py` | 固定875 MW/0.85，规划与参考使用同一模型 |
| 恢复与执行 | `src/feedback_control.py` | SOC、时钟、预测包→请求、实际动作、回传状态 |
| 尾部与参考 | `src/recovery_control.py` | 尾部超额、参考电量约束、负荷余量限制 |
| 实验读取 | `src/fusion_evidence.py` | 冻结JSON/CSV→校验后的汇总与轨迹 |
| 独立复算 | `scripts/verify_envelope_results.py` | 哈希、114条轨迹、96组配对区间 |

## 状态与物理参数

容量30,000 MWh，初始/运行上限/日末目标15,000 MWh，硬下限4,500 MWh。
名义功率1,250 MW、效率0.92；规划使用875 MW、效率0.85的下界。
每小时执行一次，跨日保持连续电量。控制器读取当前SOC与可用预测；
场景实际参数进入执行仿真器和事后核算。

```text
E[t+1] = E[t] + eta*c[t] - d[t]/eta
N_control[t] = N_actual[t] + c_actual[t] - d_actual[t]
E_floor_next(k) = max(4500,15000-(23-k)*875*0.85)
```

## 评价设计

候选在验证期按固定预算锁定，再评价2021/2022，每年363个完整UTC日。
范围内含24条健康轨迹和6条故障轨迹；750 MW/0.80另作范围外压力试验。
SOC假设准确即时，恢复资源下界预先给定。全部年份已多轮使用，结论按探索性评价呈现。

当前界面默认回放V8冻结结果，V7仅用于同条件对照。原模型、轨迹和协议与当前修订代码分别留档。
